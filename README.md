# Гурман 05 — сайт кафе

Одностраничный сайт кафе **«Гурман 05»** (Махачкала) — домашние полуфабрикаты и горячие блюда.

## Что внутри

Один самодостаточный файл `index.html` — HTML, CSS и JS встроены, без сборки и зависимостей. Просто откройте в браузере или залейте на любой хостинг.

## Возможности

- 🏠 Hero-секция (есть место под фоновое видео)
- 🍽️ Меню с табами: горячие блюда / полуфабрикаты + цены
- 📝 Форма заказа (имя, телефон, тип заказа, адрес) с валидацией
- 💬 Кнопки WhatsApp + плавающая кнопка «Заказать»
- 🌾 Фирменный пшеничный декор из логотипа
- 📱 Mobile-first, адаптивный, плавные анимации при скролле

## Что нужно заполнить перед публикацией

Найдите в `index.html` комментарии с пометками и замените:

| Что | Где | На что |
|-----|-----|--------|
| Номер WhatsApp | `79XXXXXXXXX` (3 места) | ваш номер |
| Телефон | `+7 (XXX) XXX-XX-XX` | реальный |
| Адрес | `[Ваш адрес]` | адрес кафе |
| Часы работы | `08:00 — 21:00` | ваши |
| Соцсети | `href="#"` в футере | ссылки |
| Цены | в карточках меню | реальные |
| Видео | закомм. блок в hero | путь к `video.mp4` |
| Логотип | слоты в шапке/hero | путь к `logo.png` |

## Добавить логотип и видео

Положите `logo.png` и `video.mp4` в эту папку, раскомментируйте
соответствующие блоки в `index.html` (отмечены комментариями).
