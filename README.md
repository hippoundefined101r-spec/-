# ФОНИКА — макет интернет-магазина телефонов

Кликабельный **макет сайта** для магазина смартфонов и техники (Махачкала) — для показа
клиенту. Frontend-прототип на тестовых данных (моках), без бэкенда. Мобайл-first, тёмная тема,
анимации. Цены в рублях (₽).

> **Бренд `ФОНИКА` — текстовый плейсхолдер.** Замените на название/логотип клиента в
> `src/config.ts` (`BRAND_NAME`), когда они будут готовы.

## Стек

- **React 18 + TypeScript + Vite**
- **react-router-dom** (HashRouter — работает без серверных rewrite-ов)
- **zustand** + `persist` — корзина/избранное/заказы хранятся в `localStorage`
- **framer-motion** — анимации появления, слайдер, шторки, модалки

## Возможности (по брифу клиента)

- 🏠 Главная: hero «рассрочка 0%», промо-слайдер, категории, хиты, новинки, бренды, отзывы,
  преимущества, блог
- 🗂 Каталог: сетка карточек, поиск, фильтры (бренд, цена, память, цвет, наличие) — на мобайле
  в нижней шторке, на десктопе в сайдбаре
- 📦 Карточка товара: галерея, выбор цвета/памяти (меняет цену), характеристики, отзывы,
  похожие, видеоблок
- 🛒 Корзина → оформление: доставка (по городу/России, самовывоз), оплата (рассрочка/карта/наличные)
- ⚡ Покупка в 1 клик (модалка)
- 🔄 Трейд-ин: калькулятор обмена с доплатой
- ⚖️ Сравнение моделей
- ❤️ Избранное, 👤 Профиль, 🧾 История заказов
- 📰 Акции, Блог, О компании / гарантия

## Запуск

```bash
npm install
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # продакшен-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Структура

```
src/
├── config.ts     # бренд (плейсхолдер), город Махачкала, контакты, соцсети
├── components/    # Layout, Header, Footer, MobileTabBar, ProductCard,
│                  # PromoSlider, FilterPanel, OneClickModal, Section, ...
├── data/          # моки: products, categories, promos/reviews/blog
├── pages/         # Home, Catalog, Product, Cart, Checkout, OrderSuccess,
│                  # TradeIn, Compare, Favorites, Profile, Orders, Promo, About, Blog
├── store/         # zustand-стор (корзина, избранное, заказы)
├── utils/         # форматирование цены/рассрочки/дат
└── styles.css     # дизайн-система (тёмная тема, токены, компоненты)
```
